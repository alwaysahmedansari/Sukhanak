# سُخنک

اردو تحریروں کا پلیٹ فارم (میڈیم طرز)۔

## اسٹیک
- Next.js (App Router) اور React
- Firebase: Authentication، Firestore، Storage
- ہوسٹنگ: Vercel

## ضروریات
- Node.js 22 یا اس سے نیا (Firebase Admin SDK کی شرط)
